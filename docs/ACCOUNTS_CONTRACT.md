# Accounts and club workspaces — v0.3 integration contract

Root owns server integration, migrations wiring, combined tests, GitHub delivery. Workers own disjoint files in the shared feature branch. Node remains local loopback only: adding accounts is a tested security increment, not a claim of production hosting readiness. Python reference stays unchanged. No external provider/LLM/mail.

## Worker A: auth domain (`src/auth/`, `tests/auth.test.mjs`)

Export async `createAuth({path=null,now=()=>new Date().toISOString()}={})` from `src/auth/index.mjs`. Use built-in Node crypto scrypt with random salts, bounded credentials, constant-time comparison, random opaque session/invite tokens stored only by digest. Persistent accounts, organizations and memberships; sessions memory-only (restart logs out). Persist atomically with serialized updates and no plaintext passwords/tokens in disk/logs. Failed writes must not update in-memory state.

API: async `status()` -> `{setupRequired}`; `setup({username,password,organizationName,displayName})` -> session result; `login({username,password})` -> session result; `session(token)` -> `{user:{id,username,displayName},organizations:[{id,name,role}],csrf,expiresAt}` or null; `logout(token)`; `createOrganization(token,{name})` -> organization; `invite(token,orgId,{role})` -> `{token,expiresAt,role}` (one-time token shown only on creation); `register({inviteToken,username,password,displayName})` -> session result; `members(token,orgId)` -> sanitized members; `setRole(token,orgId,userId,{role})`; `removeMember(token,orgId,userId)`; `changePassword(token,{currentPassword,newPassword})` -> replacement session result; `authorize(token,orgId,{write=false,owner=false}={})` -> `{user,organization:{id,name,role}}` or throws Error.status 401/403/404. Session results include opaque `token` for root Set-Cookie, plus sanitized session fields. No plaintext credentials in return. Roles owner/scout/viewer. Viewer reads; scout writes scouting/import; owner additionally manages members/invites. Any authenticated user may create a fresh empty organization. Last owner protected. Revoked membership immediately denies old sessions. Invalid invites generic error, bounded expiration and consumption atomic. Max 100 users, 50 orgs, 100 sessions, 100 invitations; login rate limit; tests for expiry, reuse, role escalation, last owner, auth persistence.

## Worker B: organization storage (`src/organizations/`, `tests/organizations.test.mjs`)

Export async `createOrganizationManager({dataDir=null,legacyStatePath=null,now}={})`. `.get(orgId)` -> `{store,importQueue}` uses existing createStore and createImportQueue per validated UUID organization, independent directories `${dataDir}/organizations/${orgId}/state.json`. Memory mode separated maps. `.claimLegacy(orgId)` atomically imports the prior version-1 state exactly once into the first setup organization, preserving original file unchanged and recording completion marker; never overwrite an existing nonempty target. Exclude credentials, validate source, allow retry/restart without duplicate migration. Root passes legacyStatePath only for CLI, tests choose temp. `.idle()` waits all queues. Organization IDs are validated, never filesystem traversal. Isolation includes job IDs, imports, decisions, tasks, audit, idempotency and file paths. Prevent two managers/processes opening same dataDir with exclusive lock while active; `.close()` drains and releases lock. Crash-recovery policy explicit; don't automatically override a live lock. Lock file may use PID process-liveness check. Add storage stats helper `.stats(orgId)` -> sanitized counts/limits/mode for UI account screen, no source contents. Keep existing store/queue modules untouched unless agreed root.

## Root HTTP

`createApp` defaults `authRequired:true`; old regression helpers opt into `authRequired:false` explicitly, never CLI default. CLI uses dataDir `.local`, legacy state `.local/state.json`, auth file `.local/accounts.json`. Protected workspace routes require authenticated HttpOnly SameSite=Strict cookie `omniscout_session` and `X-Omniscout-Organization` (UUID; membership checked server-side). Every import, state, player, export, decision, task, brief, coverage route uses authorized organization store and queue. For `?dataset=demo|import`, workspaces remain separated inside that organization. A client-supplied body org/tenant field cannot override server authorization. Owner/scout may mutate; viewer gets 403. Audit records actor user ID.

GET `/api/session` remains public: `{mode:'local_accounts',authenticated:false,setupRequired,csrf,supportsImport:false}` before login. Root creates random HttpOnly SameSite Strict preauth cookie+CSRF for setup/login/register, validates same origin and nonce. Authenticated session -> `{mode:'local_accounts',authenticated:true,user,organizations,csrf,expiresAt,supportsImport:true,persistence:'local_file'|'memory'}`. `/api/health` and static assets/sample public synthetic. All other `/api/*` protected.

POST `/api/auth/setup` {username,password,displayName,organizationName}; `/api/auth/login` {username,password}; `/api/auth/register` {inviteToken,username,password,displayName}; `/api/auth/logout` {}; `/api/auth/password` {currentPassword,newPassword}. Auth success returns sanitized session (never cookie token); sets HttpOnly cookie. Setup claims legacy data before usable session returned. `/api/auth/organizations` POST {name}; `/api/auth/members` GET; `/api/auth/invites` POST {role}; `/api/auth/members/:userId` PATCH {role} or DELETE; all organization management uses header. `/api/workspace/stats` GET -> sanitized stats. No email is sent; invitations are manually shared local codes. Root creates optional endpoint `/api/auth/recover-migration` owner-only if claim legacy fails, preserving setup retry path.

## Worker C: interface (`public/` only)

Add first-run setup, login and invite registration screens; authenticated account/club selector, local invite/member/role management, password change/logout. Detect local_accounts and never fall back to browser demo on 401/server failure. After logout/session expiry clear in-memory catalog/state/dialogs/import payload/jobs, leave only public synthetic demo if explicit standalone environment. Never store credentials, sessions, source data, invitation codes in localStorage; preference IDs only. Every protected read/write and CSV download sends X-Omniscout-Organization; every mutation uses current csrf. Organization switching flushes prior content and guards stale async responses; keep password inputs autocomplete appropriate. Viewer controls explain read-only and avoid suggesting successful writes. Retain mobile, keyboard, dataset/import UI and standalone/edge synthetic compatibility. Test selectors stable: #auth-form, input[name=username], input[name=password], #organization-select, nav data-view=account. Root owns browser scripts/build.

## Evidence

Tests must include two users/two organizations sharing identical player/job/request IDs, wrong/missing org headers, role-restricted imports/exports/member management, expired/revoked sessions, invite reuse, CSRF, password change, persistence/restart, original legacy state preserved, browser club switch/logout with no previous data visible. Root later assigns independent review after A/B/C implementation.
