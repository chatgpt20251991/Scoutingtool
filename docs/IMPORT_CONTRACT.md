# Node import integration contract (v1)

Integrator-owned contract for workers A/B/C/D. Node remains the main app; Python is an unchanged reference.

## Wire format

JSON envelope: `{schemaVersion:1, snapshotId, correctionOf:null|string, asOf, source, competitions:[], players:[]}`. Source, competitions and players use the existing Node catalog camelCase fields, with strict validation. Additional required source fields: `rightsAttested:true`, `allowedUses` including ingest/store/display/analysis; explicit `expiresAt`, `validFrom`, `rightsNote`, and `status` synthetic or approved (importer declaration, not independently verified). Required player fields include `provider`, `providerId`, `identityStatus` (provider_id or verified; needs_review is a blocking conflict), `sourceId`, `competitionId`, `dob`, `role`, `synthetic`, four timestamps and `stats`. Stats include `snapshotId`, `definition` (registered `omniscout-counts-v1`), minutes and matches (nullable), four timestamps and known nullable counting metrics. Snapshot and observation IDs are immutable; a correction uses a new snapshotId and correctionOf. IDs are bounded ASCII identifiers. No names as identity keys.

Limits: 1 MiB raw JSON, 100 competitions, 3000 players, one source per upload. Unknown measurements remain null. Competitions retain season, explicit seven-dimensional coverage, sourceId and received time. Validate rights against current wall time and availability against asOf (which cannot be future). Preserve text as untrusted text, never fetch locators. Show duplicate names as warnings without merging; disputed IDs block.

## Module boundary

Worker A owns `src/import/`, `tests/import.test.mjs`, `samples/import-demo.json`, and `docs/IMPORT_SCHEMA.md`. Exports from `src/import/index.mjs`: `MAX_IMPORT_BYTES`, `emptyImportState()`, `previewImport(payload, importState, {now}={})` returning `{valid,errors:[{path,message}],warnings:[{path,message}],summary,digest}` without writes; `applyImport(payload, importState, {now}={})` returns `{state,result}` (new state, immutable input); `rollbackImport(snapshotId, importState, {now}={})` returns same; `catalogFromImports(importState,{asOf,now}={})` returns existing engine-compatible catalog with only imported records. Invalid mutations throw an Error with status=400/409 and details. Store complete immutable snapshots and append recoverable mutation history. Exclude future or expired records on reads and preserve prior revisions.

Worker B owns `src/ingestion/`, `tests/ingestion.test.mjs`. Exports `createImportQueue({store, now})` from `src/ingestion/index.mjs`; store is existing async read()/update(syncFn). Persist queue in state.importJobs and imports in state.imports. Queue exposes async `enqueue(payload,digest)` -> job; `list()` -> jobs; `retry(id)` -> job; `idle()` -> wait until drained. Job has id, snapshotId, digest, status queued/running/succeeded/failed, attempts, maxAttempts, error, result, createdAt, updatedAt. Validate before enqueue and again before execution. Atomically apply import plus succeeded status in single store.update. Bound queue and retry, hash idempotency, recover interrupted jobs on startup, no external requests. Add adapter and coverage boundaries without assuming live provider access. Root connects server.

## HTTP contract (root)

Existing API gains `?dataset=demo|import` (default demo); decisions/tasks send `dataset` field; state is scoped. Catalog endpoint for import returns only import catalog. `POST /api/import/preview` takes raw envelope, returns preview, no writes, including on invalid content. `POST /api/import/confirm` takes `{payload,digest}`; stale/mismatched preview digest is rejected, returns 202 `{job}`. `GET /api/import/jobs` returns `{jobs}`. `POST /api/import/jobs/:id/retry` -> `{job}`. `POST /api/import/rollback` takes `{snapshotId}` -> result. `GET /api/import/sample` downloads synthetic sample. All mutations require existing session CSRF header and same origin. Oversize 413. Imported decisions/tasks/brief/audit live in state.importWorkspace, separate from demo state. Source exports require export rights.

Worker C owns public/ only. Preserve all existing views, add dataset selection and import screen with file picker, preview, errors/conflicts, rights/seasons/counts, explicit confirmation, poll actual jobs, retry, rollback. Only local backend supports imports; standalone and Cloudflare demo stay synthetic and disable import. Dataset selection survives reload; imported source labels must distinguish synthetic test imports from importer-declared, unverified data. Preserve comparisons, research and exports using scoped API. Never use browser fallback for imported state.

Worker D (root initially, independent review worker after slot opens) owns end-to-end/integration tests and final evidence. Agents must not modify each other's files. Shared worktree chosen to avoid merging initial new files; only root commits and changes contracts/server/engine/store/build.
