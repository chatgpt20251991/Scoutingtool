# Omni-Scout · Scoutingtool

Node-hoofdproject met behouden Python-referentie. De volledige bestaande broncode wordt in een afzonderlijke werkbranch geïmporteerd en getest.

De huidige applicatie is een lokaal scoutingprototype met synthetische demo, gecontroleerde JSON-import en geen aangesloten live dataproviders. Geen productiehosting.
